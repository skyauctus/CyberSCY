## 🚀 About the Project
**CyberSCY OS** is a custom Debian-based Linux distribution designed to bridge the gap for students, ethical hackers, and security enthusiasts who cannot afford high-end hardware. Traditional security OSs (like Kali or Parrot) require heavy resources (12–16GB RAM) via Virtual Machines, which is a major barrier for beginners. 

CyberSCY OS is heavily optimized to strip away unnecessary background bloatware, allowing it to run smoothly and lightning-fast on standard laptops or desktops with **as low as 4GB of RAM**!
